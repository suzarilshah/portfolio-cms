# Suzaril Shah - Portfolio Website

A modern, distinctive portfolio website for Muhammad Suzaril Shah - Microsoft MVP, Docker Captain, and Engineering Technologist.

## ✨ Design Philosophy

This portfolio breaks away from generic "AI slop" aesthetics by implementing:

- **Unique Typography**: Custom font combinations (Syne, Outfit, JetBrains Mono, Fraunces)
- **Bold Color Palette**: Cyberpunk-inspired with Malaysian twilight influences
- **Atmospheric Backgrounds**: Layered gradients, particle systems, and geometric patterns
- **Rich Animations**: Framer Motion for orchestrated page loads and micro-interactions
- **Creative Layouts**: Non-traditional component arrangements and spotlight effects

## 🎨 Features

- Interactive particle background with mouse interaction
- Smooth scroll animations and section reveals
- Responsive design for all devices
- Dynamic content sections:
  - Hero with animated badges
  - About with personal interests
  - Professional experience timeline
  - Education and research
  - Awards and certifications
  - Publications and articles
  - Community involvement
  - Contact and booking integration

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **CMS Database**: Neon PostgreSQL
- **Admin Authentication**: Stack Auth
- **File Storage**: Public Vercel Blob, with authenticated direct uploads
- **Hosting**: Vercel `portfolio-cms` in the Yayasan Insan Prihatin team
- **Styling**: Tailwind CSS with custom design system
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Self-hosted Inter and JetBrains Mono variable fonts
- **Language**: TypeScript

## 🎯 Key Sections

- **Hero**: Bold introduction with animated elements
- **About**: Personal background, interests, and skills
- **Experience**: Timeline of professional roles
- **Education**: Academic achievements and research
- **Awards**: Recognition and certifications
- **Publications**: Research papers and technical articles
- **Community**: Speaking engagements and volunteer work
- **Contact**: Booking and feedback forms
